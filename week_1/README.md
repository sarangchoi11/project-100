# project-100 (청년부 웹사이트)

청년부 코딩 동아리에서 **4주 동안** 같이 만드는 웹사이트의 디렉토리입니다 ! (신난다)

---

## 먼저 할 것

1. VS Code에서 `index_1.html` 파일을 엽니다
2. 오른쪽 아래 **Go Live** 버튼을 누릅니다
3. 브라우저에 사이트가 뜨면 성공입니다

> **Go Live가 안 보이면?**  
> VS Code 왼쪽 Extensions(네모 4개 아이콘)에서 **Live Server**를 설치하세요.

---

## 웹사이트는 어떻게 만들어지나요?

웹페이지는 크게 **3가지 재료**로 만들어집니다.

| 재료 | 하는 일 | 비유 |
|---|---|---|
| **HTML** | 제목, 글, 버튼 같은 **내용** | 집의 뼈대 |
| **CSS** | 색, 크기, 위치 같은 **꾸미기** | 집의 인테리어 |
| **JavaScript** | 버튼을 누르면 일어나는 **동작** | 집의 전기 스위치 |

이 프로젝트에서는 파일이 **3개로 나뉘어** 있습니다.

```
project-100/
├── index_1.html      ← HTML (내용)
├── index_1.css       ← CSS (꾸미기)
├── index_1.js        ← JavaScript (동작)
├── _template.html    ← 나중에 쓸 페이지 틀
└── README.md         ← 지금 보고 있는 설명서 (보통 나의 코드를 설명하는 파일이에요)
```

### 각 파일을 열면 뭐가 있나요?

**`index_1.html`** — 화면에 보이는 내용
- "명륜중앙교회 청년부" 제목
- 이번 주 공지
- 주보 / 조 / 출석 카드 3개

**`index_1.css`** — 예쁘게 꾸미는 코드
- 글씨 색, 배경 색
- 카드 모양, 버튼 모양
- 핸드폰 화면에서도 잘 보이게 하는 설정

**`index_1.js`** — 버튼을 눌렀을 때 동작
- "출석하기" 버튼을 누르면 → "출석 완료 ✓"로 바뀜

## 뭐부터 바꿔볼까요?

파일을 고치고 **저장(Ctrl+S / Cmd+S)** 하면, Go Live로 연 브라우저가 자동으로 새로고침됩니다.

### 1. 글자 바꾸기 → `index_1.html`

`<h1>`, `<h2>`, `<p>` 안의 글자를 바꿔보세요.

```html
<h1>명륜중앙교회 청년부</h1>   ← 제목
<p>오늘부터 4주 동안...</p>    ← 공지 설명
```

### 2. 색 바꾸기 → `index_1.css`

파일 맨 위 `:root` 안에 있는 `--accent` 값을 바꾸면, 버튼과 라벨 색이 한 번에 바뀝니다.

```css
--accent: #fa7a45;   /* 포인트 색 ← 여기 바꿔보세요 */
```

색 코드는 [coolors.co](https://coolors.co)에서 골라도 되고, `red`, `navy`처럼 영어 단어로 써도 됩니다.

### 3. 버튼 동작 바꾸기 → `index_1.js`

2주차에 배울 예정! 지금은 "출석하기" 버튼을 눌러보면서 동작만 확인해 보세요.

## CSS 읽는 법 (2분이면 됩니다)

CSS는 거의 전부 이 모양입니다.

```
누구를 { 무엇을: 어떻게; }
```

예시:

```css
body { background: #ffffff; }
```

→ **화면 전체(body)** 의 **배경색을** **흰색으로**

```css
button { color: #ffffff; }
```

→ **버튼(button)** 의 **글자색을** **흰색으로**

이 패턴만 알면 CSS의 대부분은 읽을 수 있습니다. 모르면 챗지피티 등등에게 물어봐도 좋습니다!

## 내가 바꾼 걸 올리기

> 2주차에 같이 합니다. 1주차에는 안 하셔도 됩니다.

VS Code 왼쪽 **가지 모양 아이콘**(Source Control)을 누르면 됩니다.

1. 뭘 바꿨는지 한 줄 적기 (예: `공지 내용 수정`)
2. **✓ Commit** 누르기
3. **Sync Changes** 누르기

터미널이 편한 분은:

```bash
git pull          # 먼저 남이 바꾼 걸 받아오기
git add .
git commit -m "무엇을 바꿨는지"
git push
```

**작업 시작 전에는 항상 `git pull`을 먼저** 하세요. 안 그러면 나중에 충돌이 날 수 있습니다.
